# STM32 DC Motor Controller with Usage-Based Lock System

An STM32-based DC motor controller developed as a team project.

The system controls a DC motor using PWM and monitors the control input through ADC. An external memory is used to store the number of usage cycles and maintain the system state between power cycles.

## Features

* STM32G030 microcontroller
* DC motor control using PWM
* ADC-based control input
* ADC with DMA
* External memory over I²C
* Usage-cycle counter
* Usage-based locking mechanism
* Different unlock sequences for different lock stages
* Direction and speed based unlock sequence
* switches for motor direction control
* Soft motor acceleration/deceleration


## Usage-Based Lock

The controller keeps track of the number of motor uses in external memory.

The system has two lock stages:

* **200 uses:** First lock stage
* **400 uses:** Second lock stage

Each lock stage uses a different unlock sequence.

The unlock sequence is based on a specific combination of:

* Motor direction
* Motor speed
* Limit switch state

After the correct sequence is detected, the usage counter is reset and the system can continue operating.

## Motor Control

The motor is controlled using PWM generated by the STM32 timer.

The firmware uses ADC measurements to determine the PWM value. A simple filtering mechanism is also applied to the ADC readings to reduce variations in the control input.

The motor speed is changed gradually during direction changes using a soft-move routine.

The system does not perform position control. Limit switches are used to detect the end positions of the motor movement.

## External Memory

An external I²C memory is used to store persistent system data, including:

* Number of motor uses
* Lock-stage information

This allows the usage counter to remain available after the controller is powered off.
